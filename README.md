# README

## 项目名称

复杂函数模拟和拒绝采样

## 项目描述

该项目使用 Python 实现了一个复杂函数的模拟，并通过拒绝采样方法生成样本数据。项目绘制了函数的曲线以及样本的统计分布直方图。

## 功能

- 计算复杂函数值
- 使用拒绝采样算法生成样本
- 绘制函数曲线
- 绘制样本的直方图

## 依赖

确保安装以下 Python 库：

- numpy
- matplotlib

## 使用方法

不出意外Ctrl+c然后Ctrl+v就能在你的pycharm里面运行了

## 结果

运行代码后，您将看到两个图形：

- 复杂函数的曲线
- 样本的统计分布直方图
